## What is bmad-auto?

`bmad-auto` is a CLI tool that automates the implementation phase of the BMAD methodology. It orchestrates Claude Code CLI to execute story-driven development loops with specialized agent roles (Scrum Master, Developer, Reviewer).

### Key Features

- **Workflow Orchestration** - SM → Dev → Review loop execution
- **State Persistence** - Resume capability with atomic YAML writes
- **Git Integration** - Auto-branch, auto-commit on approval
- **Progress Monitoring** - Rich terminal status display

## Getting Started

```bash
# Ensure Claude Code is logged in (uses subscription)
claude login

# Install dependencies
uv sync

# Run tests
uv run pytest

# Execute workflow
bmad-auto run --epic path/to/epic.md
```
